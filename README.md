# ScanBot

[![.NET](https://github.com/iberisoft/ScanBot/actions/workflows/dotnet.yml/badge.svg)](https://github.com/iberisoft/ScanBot/actions/workflows/dotnet.yml)

This software controls the film scanning bot designed for industry.

## Installation

Open https://dotnet.microsoft.com/en-us/download/dotnet/6.0, download and install two packages:
* ASP.NET Core Runtime
* .NET Desktop Runtime

Copy the latest ScanBot release to a folder and run `ScanBot`.
